# Definition of Done

## Critérios gerais

- [ ] Implementação realizada conforme os critérios de aceitação da User Story.
- [ ] Código revisado por ao menos outro integrante do time (Code Review / PR).
- [ ] Validações de entrada implementadas (campos obrigatórios, relacionamentos, valores inválidos).
- [ ] Testes manuais realizados seguindo um roteiro mínimo (menus, fluxos principais e casos de erro).
- [ ] Sem erros críticos ou travamentos (crash) durante o uso normal do menu.
- [ ] Projeto compila sem erros e sem warnings relevantes.
- [ ] Funcionalidade integrada ao sistema (acessível pelo menu correspondente ao perfil correto).
- [ ] Persistência verificada: os dados criados/alterados continuam corretos após reiniciar o programa.
- [ ] Controle de acesso por hierarquia verificado (Administrador/Técnico/Cliente vê somente o que deve ver).
- [ ] Critérios de aceitação da User Story totalmente atendidos.
- [ ] Pull Request aprovado por outro integrante do time.
- [ ] Código integrado à branch principal (`main`).
- [ ] Documentação impactada atualizada (requisitos, backlog, user stories, arquitetura ou decisões, conforme o caso).
