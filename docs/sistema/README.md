🎯 Ambientação e Propósito do Arquivo
Este arquivo contém o ponto de partida do sistema ByteTech executado via terminal. Ele é responsável por renderizar a interface base (Menu Principal), capturar as opções do usuário com tratamento de erros, e gerenciar o fluxo de autenticação (Login) de forma visualmente fiel aos protótipos do projeto.

O código foi escrito de forma puramente estruturada (sem orientação a objetos), utilizando bibliotecas nativas da linguagem C para manipular a interface de texto, entrada de dados e obtenção da data do sistema.

Neste momento, o arquivo atua como o "esqueleto" do sistema. Ele valida o login e redireciona o usuário para menus simulados de cada perfil, que deverão ser expandidas futuramente com as regras de negócio de cada ator.
